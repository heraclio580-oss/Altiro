Altiro builds a combined running and strength training plan. The demo account already has a plan and a few
weeks of logged workouts.

Things to try:
- **Today:** tap Start Workout to time a workout and log sets, weights and reps; + Add Workout adds anything
  extra, including classes; **Track a run with GPS** records a run with its map.
- **Plan:** the week's workouts; hold and drag one to move it. The wrench (Adjust) changes the plan.
- **Calendar:** tap a past day to log a workout or give a reason for missing one.
- **Progress:** weekly workouts, miles, time, sets, reps and personal records.
- **Settings:** workout reminders (local notifications at the chosen time), Strava connection (optional; needs
  the reviewer's own Strava account), a guided tour, Help & support, and **Delete account**, which permanently
  deletes the account and all of its data.

GPS run tracking: on Today, tap **Track a run with GPS** (or Start Workout on a run → **Track this run with
GPS**), then Start. Altiro measures distance, pace and mile splits and draws the route on a map. It asks for
location "while using the app"; the "location" background mode is used only to keep tracking a run the user
started while the screen is locked (with the blue location indicator showing), and stops when they finish.
Location isn't used at any other time except the optional weather forecast.

Strava: Altiro only reads the user's own runs, to log them to their plan. Connecting is optional, and nothing
else in the app depends on it.

Apple Health / Health Connect: Settings → Connected Apps → **Connect Apple Health** (iPhone) or **Connect
Health Connect** (Android). Optional. Altiro only reads: runs recorded by the user's watch from the last 7
days (with their distance and calories), so they're logged to the plan, and today's step count, shown on
Today. It never writes health data, doesn't share it, and doesn't use it for ads. If the test device has no
runs in Health, the connection still shows today's steps.

Health: Altiro gives general training guidance, not medical advice. The Terms of Use include a health
disclaimer (Settings → Terms of use).
